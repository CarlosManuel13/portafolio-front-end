# 🌐 Portafolio Front-End

¡Bienvenido! Este repositorio contiene la landing page principal de mi portafolio web personal, diseñada desde cero enfocándome en una interfaz limpia, moderna y con un diseño estético cuidado.

A nivel profesional me enfoco en el mundo del **DevOps y Cloud Engineering**, pero considero que entender el Front-End y cuidar la presentación visual es clave para entregar productos de software excepcionales.

---

## 🚀 Tecnologías Utilizadas

*   **HTML5:** Estructura semántica y accesible.
*   **CSS3:** Estilos personalizados, diseño adaptativo y efectos visuales modernos (como el efecto *glow* de neón).
